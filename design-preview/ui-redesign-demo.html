05 · Validation

Real-time validation with scroll-to-error

Fields are checked when you leave them, then on every keystroke. On submit, the first invalid field scrolls into view, gets focus and shakes. A summary at the top links to every error. This pattern goes into every form in the project.

After approval, this is the rollout order

  1. Tokens + keyframes in index.css, Geist font, delete Vite boilerplate CSS
  2. Rebuild the primitives: Button, Input/Select, Badge, Card, Modal, ConfirmDialog, Toast, Table (skeleton + empty), Pagination
  3. Add a useFormValidation hook (rules, touched state, live checks, scroll-to-first-error) and wire it into all 12 forms and modals
  4. Restyle Sidebar, Header and Login, then each page: Dashboard → POS → Products → the rest
  5. Replace every window.confirm, emoji and 9–11px text, then run a final lint/build
